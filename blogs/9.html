栈和单调栈

August 01, 2026

这个页面介绍栈。

栈

你可以把栈理解成一个数据的堆，你可以往堆上放数据（push）、看最上方的那一个数据（top）、把最上方的数据拿走（pop）。

于是我们可以立刻实现一个栈。

在这里测试：https://www.luogu.com.cn/problem/B3614

struct stack {
    std::list<int> a;

    stack() {
        a.clear();
    }

    void clear() {
        a.clear();
    }

    int size() {
        return a.size();
    }

    bool empty() {
        return size()==0;
    }

    void push(int x) {
        a.push_back(x);
    }

    int top() {
        return a.back();
    }

    void pop() {
        a.pop_back();
    }
};

事实上，C++ 的 stack 头文件中有一个类 stack，就是栈，但是它的运行速度比较慢。一般来讲，我们可以直接使用 vector。

例题一：括号匹配

原题：https://www.luogu.com.cn/problem/B2165

我们在遍历字符串的过程中维护一个栈。如果当前字符是左括号，就把它放入栈中；否则如果栈顶有对应的左括号，就把它弹出，如果没有，就输出 NO。

遍历完后，如果栈不是空的，也输出 NO。

#include <bits/stdc++.h>

std::vector<char> a;

std::string s;

void solve() {
    a.clear();
    std::cin>>s;
    for(auto i : s) {
        if(i=='(' || i=='[' || i=='{') a.push_back(i);
        else {
            if(a.empty()) {
                std::cout<<"NO\n"; return ;
            }
            if(i==')' && a.back()=='(') a.pop_back();
            else if(i==']' && a.back()=='[') a.pop_back();
            else if(i=='}' && a.back()=='{') a.pop_back();
            else {
                std::cout<<"NO\n"; return ;
            }
        }
    }
    if(a.empty()) std::cout<<"YES\n";
    else std::cout<<"NO\n";
}

int main() {
    int t;
    std::cin>>t;
    while(t--) solve();
    return 0;
}

这么做的原因是如果括号序列是合法的，那么每个右括号一定匹配一个左括号，而如果它们之间还有其他东西，那么就无法匹配。有多余的左括号也无法匹配。

单调栈

这是一种特殊的栈，可以在 \(O(n)\) 的时间内求出一个数组中每个元素前最后一个比它小（或大）的数。

例如有数组 \(a=[1, 3, 2, 5, 4]\)，则每个数前最后一个比它小的数的编号是 \([0, 1, 1, 3, 3]\)（\(0\) 表示不存在）。

显然我们可以求出所有前缀最小值然后二分，但这么做是 \(O(n\log n)\) 的。

那么我们如何用栈来解决这个问题呢？

我们先观察一下朴素的做法：遍历整个数组，枚举前面所有的数，看它是否比现在的数小。

它的复杂度是 \(O(n^2)\)，因为这个算法枚举了一些无用的数。比如在上面的例子中，\(a_2=3\gt a_3=2\)，所以 \(a_3\) 以后的所有数 \(a_i\) 都不需要枚举 \(a_2\)。因为如果 \(3\) 比 \(a_i\) 小，那么 \(2\) 也一定比 \(a_i\) 小，而且 \(2\) 在 \(3\) 之后，所以 \(a_2\) 永远不可能是答案了。

所以有可能作为答案的数一定是单调递增的，我们可以用一个栈来存储它们。每当我们遍历一个数时，就把栈中所有大于等于它的元素都弹掉，此时栈顶元素就是答案。然后我们在把当前的数加进去。

注意栈中要存的是数的编号。

for(int i(1); i<=n; i++) {
    std::cin>>a[i];
    while(!st.empty() && a[st.top()]<a[i]) {
        ans[st.top()]=i;
        st.pop();
    }
    st.push(i);
}

例题二：最大的矩形纸片

原题：https://www.luogu.com.cn/problem/B4273

一个纸片的大小，取决于它的长度和区间内的最小值。所以我们先用单调栈求出每个数前最后一个比它大的位置和每个数后第一个比它大的位置（假设分别是 \(l_i\) 和 \(r_i\)，纸片高度为 \(h_i\)），这就是它作为最小值的范围，显然面积的最大值是 \(\max_{i=1}^{n}h_i\times(r_i-l_i+1-2)\)。

例题三：仓鼠窝

原题：https://www.luogu.com.cn/problem/P3400

这也是一道经典的单调栈例题。首先，我们可以递推求出每个点最多能向上多少格。

然后考虑枚举每一行，令这一行上的第 \(i\) 列上的点作为子矩阵的方案数为 \(f_i\)，能向上 \(h_i\) 格，它前面最后一个向上格数比它少的位置为 \(l_i\)，则 \(f_i=f_{l_i}+h_i\times(i-l_i)\)。最后将 \(f_i\) 累加即可。
